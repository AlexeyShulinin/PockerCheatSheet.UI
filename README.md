# Feltwise

A responsive poker hand-learning app with practice quizzes, hand rankings, and an all-hands reference.

## Run locally

```bash
npm install
npm run dev
```

## Routes

- `/` — practice identifying poker hands
- `/hands` — browse rankings and hand details
- `/hands/all` — view every hand and card example together

## Checks

```bash
npm run lint
npm run build
```
